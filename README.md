# 一分鐘鬼話

日本怪談版：裂口女、八尺大人、廁所花子、幽靈末班車、皿屋敷。五捲均為虛構改寫，每捲故事長 60 秒，另有 0.75 秒藍色 PLAY 帶頭。

## 使用

雙擊 index.html 即可在桌面觀看。手機請透過本機測試網址或 GitHub Pages 開啟。所有圖片、人聲與程式已嵌入 HTML，播放不會呼叫 Gemini。

按播放後載入人聲、進入全螢幕；瀏覽器不提供全螢幕時使用滿視窗。可暫停、靜音或停止。切換分頁自動暫停，結束後退出播放畫面；看完紀錄只存在該瀏覽器的 localStorage。

## 手機介面

手機底部固定顯示目前選中的錄影帶與播放鍵，並可點「換帶」回到櫃子。故事簡介保留在頁面；地點、錄影日期和標籤資料可展開查看。播放中的暫停、靜音與停止按鈕位於底部，避開手機安全區，字幕在控制列上方。支援文字放大與 reduced-motion；影片仍保留原有恐怖效果。

手機播放鍵高至少 52 CSS px，播放控制鍵高至少 48 CSS px；這些是本頁的操作設計尺寸，不代表實體裝置驗證。

## 上傳 GitHub

將本上傳包解壓縮，直接把 index.html、README.md、手機測試.md 與 .nojekyll 放在 repository 最上層。

GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save。等待部署成功，再開啟 Pages 提供的網址。

工作區的 work 與 qa 是製作／驗證資料，不必上傳。Gemini 金鑰只用於本機生成音檔；本包不含金鑰，也不需要後端。

## 恐怖加強版 v4

五捲先透過玻璃倒影、竹影、門縫、身後乘客與井口頭髮透露異狀；鬼影隨故障停頓、偏頭並向鏡頭伸手。後段鬼臉改變，保留倒頭落地、跳臉、凍結斷訊、NO SIGNAL 與黑屏五種結尾。待機電視顯示選中錄影帶的局部鬼影；封面仍是無人的老宅。沿用既有圖片，不增加大型素材。

女鬼保留既有溫柔成人女聲與原速。遠處台詞較悶、較小聲，後段更清晰並移向另一側耳邊；每捲位置不同，台詞期間降低環境音。Web Audio 合成場景材質不同的腳步、奔跑與喘息。拍攝者停止走動後，另一組腳步仍繼續；結尾前有近耳呼吸。所有聲音遵守暫停、靜音、音量、停止及 56–57 秒靜音窗口。腳步與喘息為合成音效，非真人錄音。

配音來源不受 Gemini 限制，亦可把其他 TTS 或真人錄音整理成音檔，再嵌入單頁。既有八句女鬼配音使用 Gemini 生成；本次調整音場，沒有重新生成錄音，播放時不呼叫任何配音 API。

## 人聲

45 個配音時段，使用 44 段獨立 Gemini TTS 錄音；皿屋敷最後一句與花子共用「她還在動」的同聲線錄音。每段指定角色聲線，裁切頭尾靜音、12 ms 淡入與 25 ms 淡出。本版所有人聲均以原速播放，避免變速造成音高改變；字幕依音檔實際播放長度消失。

旁白 Orus：低聲、克制、接近拍攝者現場紀錄；同行者 Puck；裂口女 Sulafat；八尺大人 Achernar；花子 Callirrhoe；井底聲音 Despina；月台報站 Kore。八句女鬼配音已重做，採溫柔、耐心、近距離的語氣，所有人聲維持原速。

取材自日本民間傳說與都市怪談，純屬虛構。全部架空改寫成 1990 年代錄影帶，時間戳使用平成與當年攝影機格式，不代表傳說的起源年代。真實地名僅作創作背景，人物與事件均為虛構。含突然驚嚇、短暫閃光與尖叫，請從低音量開始。

## 載入改善

上傳版人聲改以 64 kbps 單聲道 MP3 嵌入，原始 WAV 保留在工作區。整頁約 2.57 MB，仍為單一 HTML，五捲配音齊全。播放前顯示人聲準備進度，重新播放沿用已解碼的近期音檔。若超過 12 秒仍無法啟動，會退出等待並提示重新播放。聲音仍只在使用者按播放後啟動。
